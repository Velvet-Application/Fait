# FAIT. — Prototype iOS SwiftUI

Ce dossier contient le premier prototype iPhone natif de FAIT., destiné à être ouvert directement dans Xcode.

## Ouvrir le projet

1. Ouvrir `FAIT.xcodeproj` dans Xcode.
2. Sélectionner le schéma `FAIT`.
3. Choisir un simulateur iPhone.
4. Lancer avec `⌘R`.

Le projet cible iOS 17 et utilise uniquement SwiftUI, des données fictives locales et des services simulés.

## Contenu de cette première version

- onboarding ;
- navigation par cinq onglets ;
- accueil avec dossiers fictifs ;
- liste et détail des dossiers ;
- entrée « Confier » ;
- analyse simulée d'un courrier ;
- correction d'une donnée ;
- plan d'action ;
- validation sensible simulée ;
- preuve de résolution ;
- notifications fictives ;
- profil simplifié.

## Sécurité

Aucun backend, aucune clé, aucun envoi réel et aucune donnée personnelle ne sont inclus.
