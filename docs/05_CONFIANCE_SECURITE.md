# Confiance et sécurité

## Principes non négociables

1. minimisation des données ;
2. consentement explicite et révocable ;
3. chiffrement en transit et au repos ;
4. hébergement européen ;
5. journal d'audit lisible ;
6. aucune revente de données personnelles ;
7. séparation stricte des données de Velvet ;
8. validation obligatoire des actions engageantes ;
9. possibilité d'effacer un dossier ou le compte ;
10. intervention humaine signalée clairement.

## Niveaux d'action

### Niveau 1 — Lecture

Analyser, résumer, classer et rappeler.

### Niveau 2 — Préparation

Rédiger, compléter un brouillon et proposer une action.

### Niveau 3 — Exécution validée

Envoyer, réserver ou transmettre après validation explicite.

### Niveau 4 — Délégation encadrée

Exécuter automatiquement une catégorie précise dans une limite définie. Cette étape n'appartient pas au MVP.

## Risques à traiter

- erreur d'extraction ;
- mauvaise interprétation d'un courrier ;
- fraude documentaire ;
- usurpation d'identité ;
- actions irréversibles ;
- stockage de données sensibles ;
- dépendance excessive à un modèle d'IA ;
- absence de preuve de transmission.
