# MVP v0.1

## Promesse testée

> Je transmets un document ou une demande, l'application m'explique ce qu'il faut faire, prépare l'action et suit le dossier jusqu'à sa clôture.

## Fonctions incluses

### 1. Entrée universelle

- photo d'un courrier ;
- import PDF ou image ;
- transfert d'un e-mail ;
- saisie ou dictée d'une demande.

### 2. Analyse

- type de document ;
- organisme ou entreprise ;
- échéance ;
- montant ;
- action requise ;
- niveau d'urgence ;
- pièces manquantes.

### 3. Plan d'action

- résumé simple ;
- étapes proposées ;
- action que FAIT. peut préparer ;
- action nécessitant l'utilisateur ;
- coût éventuel ;
- date cible.

### 4. Exécution assistée

- génération de courrier ou e-mail ;
- préparation d'une résiliation ;
- préparation d'une demande de remboursement ;
- création d'une relance ;
- proposition de créneau ou rappel ;
- checklist documentaire.

### 5. Suivi

- statut du dossier ;
- prochaine action ;
- relance automatique proposée ;
- documents associés ;
- historique horodaté ;
- clôture et preuve.

## Hors périmètre initial

- paiements automatiques ;
- signature autonome ;
- accès bancaire complet ;
- décisions médicales ou juridiques ;
- appels vocaux IA ;
- réservation universelle de prestataires ;
- démarches publiques totalement automatisées ;
- gestion automatique sans consentement explicite.
