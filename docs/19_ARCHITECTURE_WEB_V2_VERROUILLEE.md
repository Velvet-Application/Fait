# Architecture web V2 — Référence verrouillée

## Statut

Cette architecture est validée comme référence officielle du produit web FAIT. à compter du 3 août 2026.

## Principes verrouillés

- aucune barre latérale permanente ;
- en-tête flottant, léger et translucide ;
- dock de navigation centré en bas sur ordinateur et mobile ;
- action **Confier** surélevée et traitée comme l’action signature ;
- accueil éditorial et narratif, sans accumulation de cartes KPI ;
- dossiers présentés comme des parcours de résolution ;
- même logique métier que l’application iOS, sans imitation visuelle mécanique ;
- identité visuelle distincte de Velvet et des tableaux de bord SaaS ou IA génériques.

## Navigation

1. Accueil ;
2. Dossiers ;
3. Confier ;
4. Alertes ;
5. Profil.

## Règle de stabilité

Cette structure ne doit pas être remplacée ou réorganisée sans décision explicite. Les évolutions futures doivent améliorer les composants, les transitions, l’accessibilité et la qualité perçue sans réintroduire une navigation latérale de type dashboard.
