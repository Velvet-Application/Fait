# Roadmap 80/20

## Règle d'allocation

Velvet conserve 80 % de l'attention jusqu'à une bêta externe stable. FAIT. reste en incubation à 20 % maximum.

## Phase 0 — Socle

- vision ;
- nom de travail ;
- analyse concurrentielle ;
- périmètre MVP ;
- confiance et sécurité ;
- backlog initial.

## Phase 1 — Validation sans code lourd

- maquette ;
- page de présentation ;
- entretiens utilisateurs ;
- test de dépôt de documents ;
- traitement manuel en coulisses ;
- mesure de la confiance et de la volonté de payer.

## Phase 2 — Prototype

- authentification ;
- import ;
- extraction ;
- création de dossier ;
- plan d'action ;
- génération de réponse ;
- statuts ;
- notifications.

## Phase 3 — Bêta fermée

- 20 à 50 utilisateurs ;
- trois cas d'usage maximum ;
- assistance humaine ;
- suivi des erreurs ;
- mesure de réutilisation.

## Conditions de poursuite

1. les utilisateurs transmettent réellement des documents ;
2. ils confient plusieurs dossiers ;
3. le taux de résolution est élevé ;
4. la confiance ne se dégrade pas ;
5. une partie accepte de payer.
