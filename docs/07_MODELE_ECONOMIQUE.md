# Modèle économique — hypothèses

## Gratuit

- import limité ;
- détection des échéances ;
- rappels ;
- coffre-fort basique ;
- quelques dossiers actifs.

## Paiement à l'action

- démarche simple ;
- relance complète ;
- résiliation assistée ;
- dossier administratif accompagné.

## Abonnement familial

- dossiers illimités sous conditions ;
- plusieurs membres ;
- suivi de proches ;
- priorité ;
- assistance humaine partielle.

## B2B2C

- employeurs ;
- banques ;
- assureurs ;
- mutuelles ;
- caisses de retraite ;
- collectivités.

## Règle

Ne pas imposer un abonnement avant que l'utilisateur ait constaté une valeur concrète : argent économisé, délai évité, échéance sécurisée ou démarche terminée.
