# Parcours utilisateur

## Écran d'accueil

Trois éléments dominants :

1. bouton **Confier quelque chose** ;
2. dossiers nécessitant une action ;
3. échéances proches.

## Parcours principal

1. L'utilisateur photographie un courrier.
2. FAIT. extrait les informations.
3. L'application affiche : « Voici ce que cela signifie ».
4. Elle propose un plan d'action.
5. L'utilisateur valide les actions engageantes.
6. FAIT. génère ou exécute les actions autorisées.
7. Le dossier reste visible jusqu'à résolution.
8. L'utilisateur reçoit une confirmation : **Fait**.

## Exemple

### Entrée

« Mon assurance auto augmente le mois prochain. »

### Réponse attendue

- augmentation détectée ;
- date d'effet ;
- impact annuel ;
- options : accepter, négocier, comparer, résilier ;
- document ou message préparé ;
- validation utilisateur ;
- suivi de la réponse.

## Principe UX

Ne jamais laisser l'utilisateur avec une information sans prochaine action claire.
